# 自动化规则验收矩阵

视觉基准：`automation-list.png`、`automation-rule-detail.png`。

## 页面

- 自动化列表：场景联动/场景管理切换、运行状态、停用、编辑、删除、新增。
- 场景联动详情：新增、编辑、返回、保存、名称与说明的空值和长度边界。
- 场景详情：新增、编辑、返回、保存、名称与说明的空值和长度边界。

## 如果（触发条件）

- 设备条件：单个设备、单个设备类型。
- 参数类型：遥测、属性、事件。
- 比较符：等于、不等于、大于、小于、大于等于、小于等于、区间、包含集合。
- 比较值：普通值、最小/最大值、逗号分隔集合、事件 JSON。
- 时间条件：单次时间。
- 重复时间：每小时、每天、每周、每月。
- 时间范围：星期选择、开始时间、结束时间。
- 组合关系：同组多条件“并且”、多条件组、新增与删除。

## 那么（执行动作）

- 操作设备：单个设备、设备类型。
- 动作值：字符串、数字、布尔值、命令 JSON。
- 激活场景。
- 触发告警。
- 同一动作组多指令、多动作组、新增与删除。

## 通用视觉与交互

- 375px、390px、430px 三种移动端宽度。
- 标题保持单行；超长标题省略，不挤压返回与保存。
- 卡片圆角、描边、阴影、间距与设备列表一致。
- 蓝色主操作、绿色运行状态、红色危险操作保持统一。
- 增删入口位于卡片内部，不悬浮、不遮挡内容。
- 键盘弹出、长列表滚动、底部安全区、空数据、加载与接口错误状态。
